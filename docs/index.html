01 / QUEUE

One folder. One batch.

Add audio or video, reorder the queue, and process everything with the same settings.

02 / COMPUTE

Use your own GPU.

Pick a device, model, and precision. Follow progress and VRAM from the workbench.

03 / EXPORT

Ready for the edit.

Export SRT, WebVTT, or plain text. Keep exports beside the source or send them to one folder.

QUICK START

Run it locally.

Use Python 3.10+ with FFmpeg on PATH. For NVIDIA acceleration, use a CUDA-enabled PyTorch build compatible with your GPU. Whisper may download model weights the first time you run it.
